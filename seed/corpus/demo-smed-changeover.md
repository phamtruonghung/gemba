# SMED — shorten changeover time in four steps

## Step 0: film one real changeover

Do not improve from memory. Film one complete changeover, then sit and watch it with a timer on each segment: hunting for tools, waiting for people, fetching the mould, adjusting, trial running, re-adjusting. Do not analyse before you have this recording — every argument afterwards rests on the same footage.

## Step 1: separate outside work from inside work

"Inside" work is work that can only be done once the machine is stopped. "Outside" work is work that can be done while the machine is still running. Most of the first time saved comes from moving work: preparing the mould, fixtures, tools and paperwork before stopping the machine. This is the step that gives the fastest result and needs no investment.

## Step 2: turn inside work into outside work

Use fixture sets, a spare mould, aligning with a locating pin instead of adjusting by hand. The aim is not to buy new gear, but to make the operation independent of skill: whoever does it gets the same result.

## Step 3: cut the adjusting and trial-run cycles

Every "trial run then adjust" is one trial-and-error loop. Write down the points that must be adjusted, then turn them into a number you can read off the scale or fixture. Two trial loops left is normal; five loops left means preparation in Step 2 was lacking.

## Step 4: make it repeatable, then standardise

Prepare a changeover cart or rack with all the tools in the order they are used. Write a one-page checklist. Verify: have someone on another shift follow the checklist and compare the result with the original recording. If it differs a lot, the fault is in the checklist, not the person.
